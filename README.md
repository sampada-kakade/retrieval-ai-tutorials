# RAG Tutorials

## 🎯 Overview
This repository contains tutorials and examples for **Retrieval‑Augmented Generation (RAG)**.  
RAG combines **LLMs (Large Language Models)** with external knowledge sources, so answers are more accurate and grounded.

## ⚙️ Features
- Step‑by‑step RAG examples  
- Integration with vector databases (e.g., FAISS, Pinecone)  
- Document ingestion and embedding workflows  
- Query + retrieval + generation pipeline  
- Sample notebooks and scripts

## 🧩 Tech Stack
- Python  
- OpenAI / Hugging Face models  
- FAISS / Pinecone for vector search  
- Jupyter notebooks for tutorials
